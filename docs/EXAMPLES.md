# Hypothetical examples

Every file in `examples/` is invented solely for decision preparation. These values are not market research, a forecast, a recommendation, or approval to set prices or run a campaign. Run each command against the examples with `make examples`.

At a hypothetical USD 10 monthly price, USD 50,000 MRR corresponds to 5,000 payers. At an illustrative 10% monthly loss, 500 replacements are needed just to hold that payer count. These are arithmetic identities, not acquisition forecasts. EUR is intentionally never converted or combined with USD.

The current implementation reports only this simple steady-state payer arithmetic. It does not model cohort timing, plan durations, probability funnels, acquisition workload, expiry, price optimization, or uncertainty. Missing operational inputs must be treated as unavailable, not as zero. Do not use these examples to make a price decision.
