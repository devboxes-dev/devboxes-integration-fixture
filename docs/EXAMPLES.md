# Hypothetical examples

Every file in `examples/` is invented solely for decision preparation. These values are not market research, a forecast, a recommendation, or approval to set prices or run a campaign. Run a scenario with `build/scenario run examples/lean.ini`; compare two with `build/scenario diff examples/lean.ini examples/base.ini`.

At a hypothetical USD 10 monthly price, USD 50,000 MRR corresponds to 5,000 payers. At an illustrative 10% monthly loss, 500 replacements are needed just to hold that payer count. These are arithmetic identities, not acquisition forecasts. EUR is intentionally never converted or combined with USD.

For an explicitly hypothetical $7.99/month illustration against the same USD 50,000 target, the simple calculation requires `ceil(50000 / 7.99) = 6,258` payers. At the calculator's stated illustrative 10% monthly loss assumption, replacement workload is `ceil(6,258 × 0.10) = 626` payers per month. $7.99 is **not approved or represented as a real price**; this is not a forecast and omits all unavailable inputs and operational uncertainty.

The scenario diff command reports changed key/value inputs and the corresponding simple payer count, and refuses cross-currency comparisons. `--currency CODE` can explicitly constrain a single run or both sides of a diff, for example `build/scenario diff examples/lean.ini examples/base.ini --currency USD`; a mismatch is an error, never a conversion. Generate one self-contained HTML report per scenario with `build/scenario report examples/lean.ini lean-report.html` (the file is generated locally and should not be committed). Reports repeat the hypothetical-only label and state coverage limitations. `montecarlo` requires explicit `loss_min`, `loss_max`, `activation_min`, and `activation_max` values (probability fractions between 0 and 1); existing examples do not contain those inputs, so the analysis is unavailable for them unless an operator supplies hypothetical ranges. It uses seeded, independent uniform draws; these samples are illustrative and not empirical probabilities. `lint` scans an INI file for heuristic indicators such as email/URL patterns, live-data wording, or unusually large financial values. A warning is not proof that data is real; no warning is not proof that an example is hypothetical. Warnings never print the potentially sensitive matched value. The calculator still does not model cohort timing, plan durations, price optimization, or uncertainty outside the supplied ranges. Missing operational inputs must be treated as unavailable, not as zero. Do not use these examples to make a price decision.
